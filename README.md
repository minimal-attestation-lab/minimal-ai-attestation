# Minimal AI Attestation (MA-01)

Minimal framework to describe responsibility boundaries in AI-assisted operations.

## Overview
Minimal AI Attestation is a minimal framework to describe
responsibility boundaries in AI-assisted operations.

It exists to make clear:
- what AI did,
- what humans did,
- and where final responsibility remains.

This framework is intentionally minimal.

## Definition
Minimal AI Attestation is a minimal written unit that allows
third parties to understand who performed which actions using AI
and who holds final responsibility for the outcome.

## Scope
This framework applies to:
- AI-assisted content generation
- AI-assisted information structuring
- AI-assisted drafting workflows

This framework does NOT cover:
- autonomous execution
- automated decision-making
- legal, medical, or professional judgments
- certification or compliance guarantees

## Positioning
Minimal AI Attestation is an operational reference.

It is NOT:
- legal advice
- a certification scheme
- a compliance framework
- a liability shield

## Responsibility Principle
AI may assist in execution or drafting,
but responsibility always remains with the human or organization
that deploys the AI output.

AI itself is not a responsible entity.

## Intended Use
This framework is intended to be:
- attached to AI-assisted outputs
- referenced in internal documentation
- used as a minimal disclosure note for third parties

## Compatibility
This framework can be used alongside:
- ID / DID systems
- internal audit logs
- existing governance or risk frameworks
